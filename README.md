# Linko — رابط کاربری (GitHub Pages)

این مخزن فقط بخش فرانت‌اند (رابط کاربری) پروژهٔ **لینکو** را نگه می‌دارد و از طریق
**GitHub Pages** سرو می‌شود.

- منطق برنامه (API، دیتابیس D1، ریدایرکت لینک‌ها) روی Cloudflare Worker اجرا می‌شود.
- آدرس ورکر: `https://linko01.moviran2018.workers.dev`
- ورود به پنل: [admin/login.html](admin/login.html)

## چطور کار می‌کند؟

فایل `js/config.js` به‌صورت خودکار تشخیص می‌دهد که صفحه از `github.io` سرو شده است و
تمام درخواست‌های API را به آدرس Worker می‌فرستد. به همین دلیل هیچ نیازی به تنظیم دستی
نیست؛ همین پوشه کافی است.

## ساختار

```
index.html        صفحهٔ اصلی
admin/            صفحات پنل (ورود، داشبورد، لینک‌ها، تحلیل‌ها، کاربران، تنظیمات)
js/               منطق فرانت‌اند
css/              استایل
```

## بروزرسانی

محتویات این پوشه باید با پوشهٔ `public/` مخزن خصوصی لینکو همسان باشد.
